# Inferno

This was my first test run with bitsquish. I wasn't entirely sure what I could use it for, so I started experimenting and seeing just what effects I can squeeze out of it. In particular, since a big advantage is that it allows me to apply traditional painting techniques to pixel art, I wondered what happens when I try to apply my non-existent painting skills to the tool. Some things worked, some things didn't, but overall it turned out interesting I think.
